Knapp för alla åtgärder; primary för sidans huvudåtgärd (max en per vy).

```jsx
<Button variant="primary">Skapa rapport</Button>
<Button variant="secondary" size="sm">Exportera</Button>
```

Varianter: primary (blå), secondary (vit med kant), ghost (transparent), danger (röd). Storlekar: sm 30px, standard 38px, lg 46px.
